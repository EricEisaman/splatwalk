# SplatWalk 0.6.6

Host / demo release (2026-07-24). WASM `api_version` remains **2**; `@splatwalk/core` pin stays **0.6.5**.

## Highlights

- **NavKit** product pack: `navkit-<slug>.zip` with `meta-nav.json`, original splat under
  `model/`, and baked artifacts under `nav/`.
- Workbench, Vuetify Fast Nav, and R3F: **Download NavKit** and drop/choose a kit to restore
  model + Live nav without re-running Fast Nav.
- Legacy nav-artifacts download/upload kept and labeled as legacy.
- `npm run check:navkit` contract smoke test.

See [`docs/navkit.md`](../navkit.md) and [`CHANGELOG.md`](../../CHANGELOG.md).
