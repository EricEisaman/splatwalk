# SplatWalk 0.6.10

Host patch release (2026-07-24). WASM `api_version` remains **2**.
Published package: **`@splatwalk/core@0.6.10`**.

## Highlights

- **NavKit camera** — `camTarget` preferred restore; engine-agnostic meta; orbit
  `setPosition` fix for saved eye pose.
- **NavKit player yaw** — oriented `+yaw` on all demos; hold tip after restore
  until click / WASDQE (travel-facing no longer steals meta yaw).

## Publish (manual)

```bash
npm run build:wasm
npm run build:package
npm publish ./dist-pkg --access public --otp=XXXXXX
```
