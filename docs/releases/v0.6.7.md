# SplatWalk 0.6.7

## React NavKit restore

Mislabeled gzip `.spz` members named `*.ply` (from R3F recompute rewriting the model
filename) crashed `DropInViewer` on restore. Fixed by magic-byte sniffing in
`normalizeSplatToPly`, reconciling the extension on Download NavKit, and preserving
the real filename across recompute.

Host/demo package patch (2026-07-24). WASM `api_version` remains `2`;
`@splatwalk/core` pin remains `0.6.5`.

## Highlights

- **NavKit navigable restore** — packs include `nav/walkable_floors.glb` (Recast debug
  mesh) so Workbench, Vuetify, and R3F restore a **green clickable overlay** with the
  crowd. Without it, PLAYER/NPC could spawn but click-to-move was a no-op.
- **R3F NavKit load** — unsticks DropInViewer dispose hang during splat reload; NavKit
  restore completes in seconds after the splat draws.
- **Workbench** — removed legacy **Upload nav artifacts** UI; use **NavKit** drop /
  choose only. Toolbar **Download NavKit** remains beside Component Pack.
