# SplatWalk 0.6.8

Host/demo package patch (2026-07-24). WASM `api_version` remains `2`;
`@splatwalk/core` pin remains `0.6.5`.

## Highlights

- **NavKit meta pose + controls** — `meta-nav.json` carries `controls.mode`
  (`click_to_move` / `wasdqe` / `both`), `region` AABB, `camPos` / `camEulerDeg`,
  and `playerPos` / `playerEulerDeg` (oriented / nav space).
- **WASDQE player locomotion** — W/S move, A/D turn, Q/E strafe on Recast crowd
  agents (Babylon Viewer + R3F). Not FreeCamera fly.
- **Controls UI** on Workbench, Vuetify, and React — live mode switch; Download
  NavKit writes the current selection.
