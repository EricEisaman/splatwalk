# SplatWalk 0.6.9

Host + core release (2026-07-24). WASM `api_version` remains **2**.
Published package: **`@splatwalk/core@0.6.9`**.

## Highlights

- **NavMesh Editor** — modes **1** Vertex / **2** Circle / **3** Global Y;
  circle click-pin and ±0.1 m radius (no drag-resize); **T** / **F** / **X**;
  Apply to Live Navmesh; NavKit downloads include rebuilt `walkable_floors.glb`.
- **Core on npm** — first registry publish of the post-0.6.4 WASM (`fast_nav`,
  SDF-MC floor project, region cull, etc.).

## Publish (manual)

```bash
npm run build:wasm
npm run build:package
npm publish ./dist-pkg --access public --otp=XXXXXX
```

See [`RELEASING.md`](../../RELEASING.md).
